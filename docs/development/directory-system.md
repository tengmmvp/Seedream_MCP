# 目录体系统一设计

本文件规定 Seedream MCP 的目录体系，以及建立在其上的权限管理。目录体系定义各目录的求值规则，是权限体系的地基；权限体系以这些目录为边界，规定各类数据的读取与写入。

## 一、核心概念

- **回退链**：声明缺席时的系统默认递补序列。进程启动目录可写时取进程启动目录，否则取用户主目录。
- **工作根目录**：取 MCP Roots 首项、`SEEDREAM_WORKSPACE_ROOT` 或回退链的先到者。
- **工作区**：客户端声明 MCP Roots 时为全部 Roots，未声明时为工作根目录。
- **数据根目录**：数据体系的根，取 `SEEDREAM_DATA_ROOT`，未声明时回退到工作根目录；服务的数据统一收在其 `.seedream` 子目录内。

## 二、设计原则

**原则一 · 顺位求值**

每个目录位置由一条声明链推导。链上环节先到先得：前一环节生效则后续让位，前一环节缺席时由后一环节递补。

**原则二 · 职责单一**

每个声明只负责一类事物：存储类声明给出数据根目录，工作类声明给出工作位置；存储类声明不参与工作区与工作根目录的求值。

**原则三 · 权限分层**

权限分整体与类别两层：每类数据各有自己的读权限与写权限，整体权限是各类别权限的总括。任何权限表述都必须明确所指的层次与类别，不允许拿单一类别的权限充当整体权限。

## 三、目录体系

### 3.1 声明

| 声明源                    | 级别   | 类别 | 语义                 |
| ------------------------- | ------ | ---- | -------------------- |
| `save_path`               | 调用级 | 存储 | 本次调用的保存目录   |
| MCP Roots                 | 会话级 | 工作 | 工作位置的主来源     |
| `SEEDREAM_DATA_ROOT`      | 部署级 | 存储 | 数据根目录的显式声明 |
| `SEEDREAM_WORKSPACE_ROOT` | 部署级 | 工作 | 工作位置的显式声明   |
| 系统默认                  | 系统级 | 工作 | 工作位置的最终回退   |

save_path 是本次调用的临时保存目录。相对路径以图片目录为基准解析；绝对路径可指向任意合法位置。它只指定本次结果的写入位置，产出的文件不因写入获得读取权限。产出文件以绝对路径回显，仅用于告知位置；需要回流迭代的目录应声明为 MCP Roots 或 `SEEDREAM_WORKSPACE_ROOT`，纳入工作区。

### 3.2 求值规则

工作根目录：

```
工作根目录 = MCP Roots 首项
           > SEEDREAM_WORKSPACE_ROOT
           > 回退链
```

数据根目录：

```
数据根目录 = SEEDREAM_DATA_ROOT
           > 工作根目录
```

数据目录布局：

```
图片目录       = <数据根目录>/.seedream/images
缩略图缓存目录 = <数据根目录>/.seedream/thumbs
日志目录       = <数据根目录>/.seedream/logs
```

### 3.3 求值时机

未声明 `SEEDREAM_DATA_ROOT` 时，图片目录与缩略图缓存目录随会话求值，跟随 MCP Roots 的变化。日志目录在进程启动时求值一次，不读取 MCP Roots：

```
日志目录 = SEEDREAM_DATA_ROOT
         > SEEDREAM_WORKSPACE_ROOT
         > 回退链
```

首次求值时记录一次图片目录位置，便于部署排查。

## 四、权限体系

### 4.1 类别权限

各数据类别各有读取与写入，范围与执行者如下：

| 数据类别   | 读                                                                    | 写                                             |
| ---------- | --------------------------------------------------------------------- | ---------------------------------------------- |
| 用户文件   | 工具读取，范围即工作区                                                | 不写                                           |
| 图片       | 工具读取，范围为工作区 ∪ 图片目录；服务读取图片目录内的源图生成缩略图 | 自动保存写入图片目录，save_path 可指定其他位置 |
| 缩略图缓存 | 服务读取，范围即缩略图缓存目录                                        | 服务写入                                       |
| 日志       | 供部署方直接查阅，不经工具                                            | 服务写入                                       |

### 4.2 整体权限

整体读权限为各类别读取范围的总括，即工作区 ∪ 图片目录 ∪ 缩略图缓存目录。整体写权限为各类别写入落点的总括，即图片目录、save_path 指定位置、缩略图缓存目录与日志目录。

### 4.3 工具读取判定

工具的读取判定边界为工作区 ∪ 图片目录。缩略图缓存目录仅由服务读取，不向工具开放，因此该判定边界小于整体读权限。路径解析后越出判定边界即拒绝，错误消息提示授权途径。

相对路径以图片目录为基准，且必须落在图片目录内。浏览工具的默认目录是图片目录。

路径校验在权限判定之前执行，拒绝以下形态：含空字节、UNC 形态、含冒号的路径分量、驱动器相对路径、有根无盘符路径；拒绝含冒号的分量是为防 NTFS 备用数据流访问。

Web 操作台与 MCP 会话共用同一求值链与权限判定；缩略图与原图端点按图片目录相对路径寻址，仅提供图片目录内的图片。

## 五、生命周期管理

图片目录：图片按日期与工具名组织保存；按 `SEEDREAM_AUTO_SAVE_CLEANUP_DAYS` 清理过期文件，按 `SEEDREAM_AUTO_SAVE_MAX_TOTAL_BYTES` 超限驱逐最旧文件。清理与驱逐只作用于图片目录内部；save_path 保存的文件可能与其他数据同目录，不属服务专有，不参与清理与驱逐。

缩略图缓存目录：按源图 mtime 与大小寻址，有独立的累计字节上界，超限按最旧驱逐；缓存文件名不带图片扩展名，不进入目录扫描与图片清理的视野。

日志目录：按 `SEEDREAM_LOG_ROTATION_SIZE` 轮转并压缩归档，按 `SEEDREAM_LOG_RETENTION_DAYS` 清理超期归档。

## 六、场景矩阵

下表为部署级声明的全组合。表中 `DATA_ROOT` 即 `SEEDREAM_DATA_ROOT`，图片目录列与读权限列中的 `DATA_ROOT` 均指其派生的图片目录；读权限为工具的读取判定边界。save_path 调用时叠加于任一行：该次写入改道至指定位置，管理边界仍是部署级图片目录。

| Roots | `WORKSPACE_ROOT` | `DATA_ROOT` | 工作根目录     | 图片目录            | 读权限                     |
| ----- | ---------------- | ----------- | -------------- | ------------------- | -------------------------- |
| ✓     | ✓                | ✓           | Roots 首项     | DATA_ROOT           | 全部 Roots ∪ DATA_ROOT     |
| ✓     | ✓                | ✗           | Roots 首项     | Roots 派生          | 全部 Roots                 |
| ✓     | ✗                | ✓           | Roots 首项     | DATA_ROOT           | 全部 Roots ∪ DATA_ROOT     |
| ✓     | ✗                | ✗           | Roots 首项     | Roots 派生          | 全部 Roots                 |
| ✗     | ✓                | ✓           | WORKSPACE_ROOT | DATA_ROOT           | WORKSPACE_ROOT ∪ DATA_ROOT |
| ✗     | ✓                | ✗           | WORKSPACE_ROOT | WORKSPACE_ROOT 派生 | WORKSPACE_ROOT             |
| ✗     | ✗                | ✓           | 进程启动目录   | DATA_ROOT           | 启动目录 ∪ DATA_ROOT       |
| ✗     | ✗                | ✗           | 进程启动目录   | 启动目录派生        | 启动目录                   |

## 七、演进约束

- 新增字段：先确定级别与类别，再按求值规则插入对应链位；
- 新增消费方：只读求值结果与权限判定，不自行拼接位置逻辑；
- 调整权限：先明确层次与类别，整体权限随类别权限同步重算；
- 替换实现：求值链单点实现，消费方不受波及。
