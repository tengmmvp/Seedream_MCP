# 目录体系统一设计

## 一、设计原则

**原则 1 · 顺位求值**

每个位置概念由一条声明链求值：存储根一条，基座一条，顺位规则同构——调用级高于部署级，会话级高于部署级，显式声明高于系统默认。前者生效则后者让位，前者缺席时后者递补。

**原则 2 · 职责单一**

每个字段只声明一类事物：存储类直接给出存储位置，工作类提供工作位置。存储类声明不改变工作区，工作类声明不直接指定存储根。

**原则 3 · 读写包含**

写权限恒为读权限的子集。读权限 = 全部生效工作位置声明 ∪ 存储根。

## 二、体系设计

### 字段定位

| 声明源                        | 声明类别        | 角色                                |
| ----------------------------- | --------------- | ----------------------------------- |
| `save_path`                   | 存储类 · 调用级 | 本次调用的临时存储指定              |
| `SEEDREAM_AUTO_SAVE_BASE_DIR` | 存储类 · 部署级 | 存储位置的显式声明                  |
| MCP Roots                     | 工作类 · 会话级 | 工作位置的主力来源                  |
| `SEEDREAM_WORKSPACE_ROOT`     | 工作类 · 部署级 | 工作位置的替补，为无 Roots 场景而设 |
| 系统默认                      | 工作类 · 系统级 | 工作位置的保底                      |

### 术语

- **工作区**：当前生效的工作位置声明集合（全部 Roots，或 `WORKSPACE_ROOT`，或用户主目录），读权限的构成单位。
- **基座**：工作区中承担派生职责的代表目录，多 Roots 时取首项。

### 位置求值

```
存储根 = save_path（本次调用）
       > SEEDREAM_AUTO_SAVE_BASE_DIR
       > <基座>/.seedream/images（派生）

基座 = MCP Roots 首项
     > SEEDREAM_WORKSPACE_ROOT
     > 用户主目录
```

`save_path` 生效时，其目标位置在本次调用内同时获得读写资格；该文件以绝对路径回显。

### 权限

| 权限 | 范围            |
| ---- | --------------- |
| 写   | 存储根          |
| 读   | 工作区 ∪ 存储根 |

写权限的作用边界同时是管理边界：图片按日期与工具组织、配额驱逐、过期清理，均只作用于存储根内部。

### 行为

| 行为   | 规则                                                                                                            |
| ------ | --------------------------------------------------------------------------------------------------------------- |
| 保存   | 写入存储根；`save_path` 生效时写指定位置                                                                        |
| 读取   | 相对路径以存储根为基准解析；绝对路径须在读权限内，越界拒绝并提示缺失配置                                        |
| 浏览   | 默认存储根，返回存储根相对路径                                                                                  |
| Web 端 | 与 MCP 会话共用同一求值链与权限；无会话声明，链落到部署级或系统默认；文件端点（缩略图、原图）仅服务存储根内文件 |

路径输入规范：空字节、UNC 形态、冒号分量（NTFS ADS）在权限判定之前拒绝。

兜底提示：无任何工作类声明时落到用户主目录，启动时记录一次存储根位置。

## 三、场景矩阵

部署级全组合（`save_path` 调用时叠加于任一行，该次存储根临时替换）：

| Roots | `WORKSPACE_ROOT` | `BASE_DIR` | 基座           | 存储根              | 读权限                    |
| ----- | ---------------- | ---------- | -------------- | ------------------- | ------------------------- |
| ✓     | ✓                | ✓          | Roots 首项     | BASE_DIR            | Roots（全部）∪ BASE_DIR   |
| ✓     | ✓                | ✗          | Roots 首项     | Roots 派生          | Roots（全部）             |
| ✓     | ✗                | ✓          | Roots 首项     | BASE_DIR            | Roots（全部）∪ BASE_DIR   |
| ✓     | ✗                | ✗          | Roots 首项     | Roots 派生          | Roots（全部）             |
| ✗     | ✓                | ✓          | WORKSPACE_ROOT | BASE_DIR            | WORKSPACE_ROOT ∪ BASE_DIR |
| ✗     | ✓                | ✗          | WORKSPACE_ROOT | WORKSPACE_ROOT 派生 | WORKSPACE_ROOT            |
| ✗     | ✗                | ✓          | 用户主目录     | BASE_DIR            | 主目录 ∪ BASE_DIR         |
| ✗     | ✗                | ✗          | 用户主目录     | 主目录派生          | 主目录                    |

## 四、演进约束

- 新增字段：确定声明类别与角色，按主从顺位插入对应链位；
- 新增消费方：只读求值结果与权限判定，不自行拼接位置逻辑；
- 调整权限：读权限保持为工作区 ∪ 存储根，写权限保持为存储根；
- 替换实现：求值链单点实现，行为层与消费方不受波及。
