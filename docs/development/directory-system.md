# 目录体系统一设计

## 一、核心概念

- **工作区**：当前生效的工作位置声明集合（全部 Roots，或 `SEEDREAM_WORKSPACE_ROOT`，或进程启动目录，或用户主目录），读权限的构成单位。
- **基准**：工作区中承担派生职责的代表目录，多 Roots 时取首项。
- **存储区**：默认保存位置与管理边界所在的目录，取 `SEEDREAM_AUTO_SAVE_BASE_DIR`，未配置时由基准派生 `<基准>/.seedream/images`。

## 二、设计原则

**原则 1 · 顺位求值**

存储区与基准各由一条声明链求值，顺位一致：会话级高于部署级，显式声明高于系统默认。前者生效则后者让位，前者缺席时后者递补。

**原则 2 · 职责单一**

每个字段只声明一类事物：存储类直接给出存储位置，工作类提供工作位置。存储类声明不改变工作区，工作类声明不直接指定存储区。

**原则 3 · 读写包含**

除 save_path 外，写权限恒为读权限的子集：读权限 = 工作区 ∪ 存储区，写权限 = 存储区。save_path 的保存位置由调用方指定，不受读权限约束，也不因写入进入读权限。

## 三、体系设计

### 字段定位

| 声明源                        | 声明类别        | 角色                                |
| ----------------------------- | --------------- | ----------------------------------- |
| `save_path`                   | 存储类 · 调用级 | 本次调用的临时保存目录              |
| `SEEDREAM_AUTO_SAVE_BASE_DIR` | 存储类 · 部署级 | 存储位置的显式声明                  |
| MCP Roots                     | 工作类 · 会话级 | 工作位置的主力来源                  |
| `SEEDREAM_WORKSPACE_ROOT`     | 工作类 · 部署级 | 工作位置的替补，为无 Roots 场景而设 |
| 系统默认                      | 工作类 · 系统级 | 工作位置的保底                      |

### 位置求值

```
存储区 = SEEDREAM_AUTO_SAVE_BASE_DIR
       > <基准>/.seedream/images

基准 = MCP Roots 首项
     > SEEDREAM_WORKSPACE_ROOT
     > 进程启动目录
     > 用户主目录
```

### save_path

save_path 是本次调用的临时保存目录：用户可自定义，路径合法即可；相对路径以存储区为基准解析，绝对路径可指向任意合法位置。它只指定本次结果的写入位置，不进入读权限；产出文件以绝对路径回显，仅用于告知位置，需回流迭代的目录应声明为工作区。

### 权限

| 权限 | 范围            |
| ---- | --------------- |
| 写   | 存储区          |
| 读   | 工作区 ∪ 存储区 |

管理边界恒为部署级存储区：图片按日期与工具组织、配额驱逐、过期清理，均只作用于部署级存储区内部。`save_path` 指定的目录可能同时存放其他文件，不属服务专有，清理与配额不得作用其上。

### 行为

| 行为   | 规则                                                                                                               |
| ------ | ------------------------------------------------------------------------------------------------------------------ |
| 保存   | 写入存储区；`save_path` 生效时写指定位置                                                                           |
| 读取   | 相对路径仅限存储区内；绝对路径须在读权限内，越界拒绝并提示授权途径                                                 |
| 浏览   | 默认浏览存储区；条目一律以绝对路径返回，可直接作为参考图路径                                                       |
| Web 端 | 与 MCP 会话共用同一求值链与权限，未声明 Roots 时链落到部署级或系统默认；文件端点（缩略图、原图）仅服务存储区内文件 |

路径输入规范：空字节、UNC 形态、冒号分量（NTFS ADS）、驱动器相对与有根无盘符形态在权限判定之前拒绝。

**兜底提示**：无任何工作类声明时落到进程启动目录，不可写则回退用户主目录；首次求值时记录一次存储区位置。

## 四、场景矩阵

部署级全组合（`BASE_DIR` 即 `SEEDREAM_AUTO_SAVE_BASE_DIR`；`save_path` 调用时叠加于任一行：该次写入改道至指定位置，管理边界仍为部署级存储区）：

| Roots | `WORKSPACE_ROOT` | `BASE_DIR` | 基准           | 存储区              | 读权限                    |
| ----- | ---------------- | ---------- | -------------- | ------------------- | ------------------------- |
| ✓     | ✓                | ✓          | Roots 首项     | BASE_DIR            | Roots（全部）∪ BASE_DIR   |
| ✓     | ✓                | ✗          | Roots 首项     | Roots 派生          | Roots（全部）             |
| ✓     | ✗                | ✓          | Roots 首项     | BASE_DIR            | Roots（全部）∪ BASE_DIR   |
| ✓     | ✗                | ✗          | Roots 首项     | Roots 派生          | Roots（全部）             |
| ✗     | ✓                | ✓          | WORKSPACE_ROOT | BASE_DIR            | WORKSPACE_ROOT ∪ BASE_DIR |
| ✗     | ✓                | ✗          | WORKSPACE_ROOT | WORKSPACE_ROOT 派生 | WORKSPACE_ROOT            |
| ✗     | ✗                | ✓          | 进程启动目录   | BASE_DIR            | 启动目录 ∪ BASE_DIR       |
| ✗     | ✗                | ✗          | 进程启动目录   | 启动目录派生        | 启动目录                  |

## 五、演进约束

- 新增字段：确定声明类别与角色，按主从顺位插入对应链位；
- 新增消费方：只读求值结果与权限判定，不自行拼接位置逻辑；
- 调整权限：读权限保持为工作区 ∪ 存储区，写权限保持为存储区；
- 替换实现：求值链单点实现，行为层与消费方不受波及。
